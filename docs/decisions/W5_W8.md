# W5-W8 Decision: From Localization to Evidence Package

Date: 2026-05-24

## Decision

W5-W8 converts the W4 step-localization gate into a compact evidence package aligned with the refined plan and related-work threat radar. The differentiator is no longer the bare claim that latents are weakly used; it is a reproducible causal protocol that separates encoding, usage, retention, and step localization.

## Week Goals

- **W5 Capacity Sweep:** run true LVR hidden-feedback step sweeps at multiple latent budgets (`lvr_steps=2/4/8/16`) on 50 paired SPD-Faith samples.
- **W6 Targeted Replication:** rerun the W4 best step (`step_index=4` at `lvr_steps=8`) as a targeted intervention gate.
- **W7 SPD Regression Scale-Up:** rerun six W2/W3 v2 metrics on 200 paired SPD-Faith samples across Qwen2.5-VL-3B, Qwen2.5-VL-7B, and LVR-7B.
- **W8 Evidence Pack:** generate a single reviewer-facing evidence pack from W3-W7 artifacts with explicit scope boundaries.

## Official Entry Points

- Capacity configs: `config.lvr_latent_patch.stepsweep_s2.yaml`, `config.lvr_latent_patch.stepsweep_s4.yaml`, `config.lvr_latent_patch.stepsweep.yaml`, `config.lvr_latent_patch.stepsweep_s16.yaml`
- Targeted best-step config: `config.lvr_latent_patch.beststep_s8.yaml`
- SPD scale config: `config.spd_faith.week7_scale.yaml`
- Validators: `tools/validate_capacity_sweep.py`, `tools/validate_w4_stepsweep.py`, `tools/validate_w3_latent.py`, `tools/validate_spd_range.py`
- Evidence pack builder: `tools/build_evidence_pack.py`

## Scope Boundary

W5-W6 are true inference-time LVR hidden-feedback intervention gates. W7 remains query-span regression evidence across model weights. Broader tasks, external paradigms such as Monet/CrystaL, and layer-level localization remain future work.
