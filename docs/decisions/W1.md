# Week 1 Decision Record

## Summary

Week 1 closed the reproducibility and instrumentation foundation for the LVR mechanistic audit. The code now supports legacy metric aliases, preregistration locks, paired-data loader interfaces, sparse LVR generation tracing, bootstrap CI summaries, and v2 metric skeletons.

## Decisions

- Legacy proxy metrics are frozen as regression references, not primary evidence for the paper claim. Use `bf3_legacy`, `pf3_legacy`, `bf1_legacy`, `bf1_layer_legacy`, `cf2_legacy`, and `lvr_trace_legacy` for baseline replay.
- Every `run_all.py` run writes `prereg.lock.json` by default from `prereg/manifest.yaml`; the manifest remains `0.1-draft` until Week 2 primary metrics are implemented.
- SPD-Faith and Maze are wired through `source_type=spd_faith` and `source_type=maze`, but real-dataset validation is pending local data staging.
- LVR trace v2 is the default path for Main-track trace evidence. The validated trace run captures real `lvr_mode_switch` state, hidden feedback, sparse decoder layers, and final hidden-state shape.
- Week 2 should build primary metrics in `pipeline/metrics/v2/` without changing existing legacy metric semantics.
