# Week 3 Decision Record

Date: 2026-05-23

Week 3 promotes the project from W2 query-span runnable-v0 validation to the first true LVR generation-time hidden-feedback intervention gate.

## Decision

- Add `lvr_latent_patch_answer_transfer` as the W3 gate metric.
- Capture real generation-loop `last_position_hidden_state` tensors from traced LVR runs.
- Patch target generation by injecting source hidden-feedback state into `forward_pre.last_position_hidden_state`.
- Keep W2 SPD metrics as regression/scale evidence only; they are not reinterpreted as latent-state intervention.

## Gate Policy

- Minimum W3 latent gate: `n=50` paired SPD-Faith samples on `lvr_7b`.
- Default latent reasoning budget: `lvr_steps=2`.
- Primary scalar: `latent_answer_transfer_rate`.
- Required counts: `n_success >= 50`, `n_patch_applied >= 50`, `n_with_lvr_mode >= 50`, `n_with_captured_state >= 50`.
- Validator: `tools/validate_w3_latent.py`.
